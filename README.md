# 记忆星脑 · Memory Nebula v2 🧠

meow-memory 记忆库的 **3D 神经元面板**，双形态：

- **DSH 桌面插件** `dsh-memory-brain`：左侧栏「🧠 记忆星脑」内嵌小界面 + ⧉ 完整网页（同源路由 `/memory-brain/*`）
- **独立网页**（备用）：`start.bat` / `python server.py`，仅本机 `http://127.0.0.1:8643`

## 八大固定分区（节点强制归类）

| 分区 | 内容 | 遗忘 |
|---|---|---|
| 🧠 大脑中枢·行为准则 | rules | **不淡化** |
| 📦 插件生态 | 自动扫描 profile：🟢在用 🟡闲置 已卸载（红点带卸载时间/原因/缺陷备注） | 状态驱动 |
| 🧩 技能库 | 自动扫描 SKILL.md：✅掌握 ⏳学习 ❌待优化；依赖插件自动连线，插件移除→淡线+【依赖插件已移除】 | 掌握不淡化 |
| 🗂 记忆库·项目档案 | project + 步骤清单（待执行/进行中/已完成/阻塞） | 正常 |
| 🧜 海马体·事实 | fact | **不淡化** |
| 💖 用户灵魂 | user + soul（人设/偏好） | **不淡化** |
| 📝 论衡·经验复盘 | lesson | 正常 |
| 💬 语言中枢·话题 | topic | 正常遗忘曲线 |

## 视图（对标生物神经元）

- 节点=细小柔和圆点（禁大光球）；连线=纤细半透明神经丝（低饱和）
- 检索/点击/激活时**光脉冲沿连线流动**；激活节点柔和高亮闪光；高频节点呼吸闪烁；衰减>70% 缓慢变暗
- 8 集群球面分离排布，一眼可辨；左侧「检索/编辑/统计」面板保留（管理操作台）
- 悬停看详情、拖拽单节点、Shift 多选后「✨ 标记为当前激活」

## 数据

- 记忆读写：`.dsh-meow/memory.db`（与插件同格式，WAL 并发安全）

## v3 新增：聚焦视图 · 配置总线 · 插件直通操作

- **聚焦视图**：点击任意分区枢纽 → 中央集群放大居中、其余 7 区变暗缩小（平滑过渡）；右侧=该分区条目列表（按调用频次排序、悬浮高亮、点击展开）；底部=统计表格（总数/活跃占比/状态数/频次排行）；点空白星空返回总览。左侧管理操作台不变。
- **全局配置总线**：主源=🧠大脑中枢（rules）+💖用户灵魂（user/soul）。主源保存自动推送（版本+1，A 类且跟随的插件记同步日志）；编辑台「📡 总线」按钮看快照/立即推送/B 类快照卡片复制；冲突裁决 override/separate/merge（`POST /api/bus/resolve`）；每插件独立「跟随全局人设」开关存 nebula.follows；全部动作写 nebula.sync_log（论衡区可查）。
- **插件生态直通操作**（聚焦插件区→右侧条目，可切「直通/只读」）：启用/禁用=改 profile bundles 清单；卸载=移出 bundles+登记红节点（时间/原因/缺陷）；重装=撤销登记；全部**重启 DSH 生效**，操作日志自动写入论衡复盘。黑名单保护：meow-memory / dsh-memory-brain / dshmarket / dsh-ops 等拒绝面板卸载。
- **中文化**：插件/技能说明走内置中文映射（46/49 覆盖，未覆盖保留英文原文并标注）；技能 desc_en 字段留原文。
- 新路由：`GET /api/bus`，`POST /api/bus/push`、`/api/bus/resolve`、`/api/plugin/action`。

## v4 增补（动画/看板/主题）

- **空闲自转**：总览绕 Y 轴缓转（图例可开关），聚焦停；**节点呼吸三级幅度**（激活闪光/高频明显呼吸/低频微弱）；连线持续低密度流光。
- **聚焦容错**：镜头优先 450ms 补间居中→面板异步加载→1.5s 超时提示不锁死；点簇区域（含 130px 感应圈）即聚焦，任意状态跨分区直切，点空白复位；点单节点只开详情。
- **底部看板**：指标卡+状态分布条+TOP5 排行+最近 5 条日志，可切「☰ 简易表格模式」。
- **🎨 主题/背景**：自动读 DSH 桌面 CSS 变量（失败静默降级）；背景三模式 A 跟随壁纸引擎（`GET /api/wallpaper-frame?id=` 代理缓存帧，无权限降级星空）/ B 内置星空 / C 自定义图；四色自定义+预设，存 `nebula.theme`。
- 翻译预加载：中文映射随 graph 下发，点击不现翻。

## v5 增补（4.1-4.4）

- **完整网页（4.1）**：iframe 每 1.5s 把聚焦分区+相机状态写入 hash；顶栏按钮读取 hash 带状态在系统默认浏览器打开；唤起失败自动复制链接并显示可点降级条；打开页从 hash 恢复同款视角。
- **轨道控制（4.2）**：左键旋转/右键平移/滚轮缩放+阻尼惯性；按下位移>4px 判拖拽不触发点击；悬停/点按钮**不停自转**，仅聚焦或拖拽时停，松手闲置 5s 恢复；缩放限制 60~1600 防穿模。
- **双轨流光（4.3)**：常驻氛围流光稳定节拍（聚焦簇内加密、远端微弱）；后台真实读写/召回/同步/插件操作经 `GET /api/events` 环形队列轮询，在对应节点连线发射更快更亮的高亮业务信号。
- **聚焦舒展（4.4）**：~450ms 内镜头居中+簇锚点上移 26（避开底部看板）+簇内节点散开 1.28 倍同步执行；远端 7 簇保持 12%~25% 淡轮廓与微流光。

## v6 增补（4.5 主题面板重做 + 4.1 唤起修复）

- **主题面板（4.5）**：左右分栏——左侧独立小渲染器实时预览（改色/切背景/拨开关即时可见，不点保存不落库）；右侧控件：四色「拾色器色块 + 色号输入框」双联动、预置配色小卡片（深海青/绯樱/松墨，色点缩略图一键套用）、背景三模式（跟随壁纸/星空/上传本地图片）、四个功能开关独立成行（文字标签/脉冲流光/连接线/空间自转）。底部【↺ 重置为默认】【取消=回滚草稿】【应用并保存=固化进 nebula.theme】。开关状态并入主题持久化，内嵌/网页共用互通。
- **完整网页（4.1 修复）**：三通道唤起——window.open → anchor 合成点击（Electron setWindowOpenHandler 对二者处理路径可能不同）→ 兜底显示链接+自动复制剪贴板；降级条常驻可手动点击重试。

## v7 增补（4.1 根治 / 4.2 交互放开 / 4.5 壁纸数据源分级）

- **完整网页根治**：桌面壳主窗经 `dsh-app://` 代理加载，页面 `location` 拼不出 http 地址（此前复制的 dsh-app:// 链接浏览器打不开属预期）。现先 `GET /api/ext-url` 向后端要真实 `http://host` 前缀（后端读 Host 头），再走三通道唤起；主窗 setWindowOpenHandler 实测对 http/https 都会 shell.openExternal，通道 1 即可命中。
- **4.2 交互放开**：相机补间只在聚焦/返回后 650ms 内生效，过渡结束完全交还控制权——总览下左键全方位旋转、右键无限制平移不再被每帧拉回；自转独立于补间（总览持续转、悬停/点按钮不停、聚焦停、拖拽松手闲置 5s 恢复）；缩放仅保留 60~1600 防穿模宽松阈值。
- **4.5 壁纸数据源分级**：①优先 DSH 壁纸引擎 GPU 实时帧（当前壁纸 id 匹配，15s 保鲜）→ ②引擎无帧时降级读 Windows 系统桌面壁纸（注册表 WallPaper），右下角小字提示「壁纸引擎未运行，已切换系统桌面图」→ ③都失败自动切内置星空不报错。下拉选项更名「跟随 DSH 壁纸引擎」。
